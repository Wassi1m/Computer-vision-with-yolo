Pourquoi YOLOv8m et pas nano/small/large ?

C'est le bon compromis : plus précis que nano/small pour détecter les petits EPI (gants, lunettes), sans être aussi lent que large/xlarge — idéal pour la vidéo temps réel.

6. Formats d'export supportés
Le modèle .pt peut être exporté vers d'autres formats selon ton déploiement :

model = YOLO("best.pt")
model.export(format="onnx")      # → interopérabilité
model.export(format="tflite")    # → mobile/embarqué
model.export(format="engine")    # → TensorRT (GPU NVIDIA max perf)
model.export(format="openvino")  # → Intel CPU optimisé
model.export(format="coreml")    # → Apple (macOS/iOS)
7. Ce que le modèle PEUT faire
Détecter simultanément plusieurs personnes dans le même cadre
Fonctionner sur image, vidéo, webcam, flux RTSP (caméra IP)
Détecter la présence ET l'absence de chaque EPI
Détecter une chute de personne (Fall-Detected)
Détecter des objets de chantier (échelle, cône)
Fonctionner à temps réel sur GPU standard
8. Ce que le modèle NE PEUT PAS faire
Identifier une personne spécifique (pas de reconnaissance faciale)
Détecter les chaussures de sécurité (classe non incluse)
Détecter les harnais de sécurité
Fonctionner en conditions de très faible luminosité sans caméra IR
Garantir 100% de précision sur les très petits objets ou personnes lointaines

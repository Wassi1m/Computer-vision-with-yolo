# ── Le piège OpenCV, à ne pas défaire ────────────────────────────────────────
# `ultralytics` déclare une dépendance vers `opencv-python`, la variante AVEC
# interface graphique. Installée, elle écrase le répertoire `cv2` de la variante
# headless : les deux paquets se partagent le même nom de module, et c'est le
# dernier écrit qui gagne. L'environnement de mesure contenait effectivement les
# deux, et `import cv2` y résolvait vers headless 4.10.0 -- pas vers le 5.0.0.93
# annoncé.
#
# Deux conséquences pratiques :
#   1. `opencv-python` est explicitement EXCLU ci-dessous. Installer avec
#      `pip install --no-deps ultralytics` puis les dépendances à la main, ou
#      réinstaller la variante headless APRÈS ultralytics :
#          pip install -r requirements-service.txt
#          pip install --force-reinstall --no-deps opencv-python-headless==4.10.0.84
#   2. Vérifier après installation, systématiquement :
#          python -c "import cv2; print(cv2.__version__)"   # doit afficher 4.10.0
#          pip list | grep -c '^opencv-python '             # doit afficher 0
#
# La variante headless est la bonne en service : le moteur tourne sans écran, et
# `opencv-python` tire des dépendances graphiques inutiles en conteneur.
